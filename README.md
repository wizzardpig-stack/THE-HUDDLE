# THE HUDDLE

A neighborhood coordination prototype for matching local needs with local offers. The product explores mutual aid, project formation, resource pooling, and lightweight community organization without follower counts or attention-driven social mechanics.

## Live

https://wizzardpig-stack.github.io/THE-HUDDLE/

## What it demonstrates

- Responsive neighborhood exchange interface
- Needs, offers, Huddles, projects, and pooled-resource flows
- Mobile navigation that converts the primary route line into a horizontal scroller
- Accessible focus states and reduced-motion support
- Local browser state for prototype interactions

## Stack

HTML, CSS, vanilla JavaScript and Canvas-based visual elements.

## Development approach

Independent product strategy, systems design, interface design, iteration, testing, and AI-assisted implementation. The goal is to explore a social product organized around practical local coordination rather than engagement metrics.
